## 화면·검증 범위

`release-assets/`, `beta-assets/`, [screenshots](screenshots/README.md)는 각 작성 시점의 오프라인 샘플 화면입니다. 최신 화면과 항목·버튼·단계 수가 다를 수 있으며 실제 BUS·AD 처리 증거가 아닙니다.

2026-10-27 기준 자동 시험은 **API 98개 통과·선택 시험 6개 건너뜀 / Client 145개 통과**입니다. 실제 Windows·Chrome·BUS·AD·SMB 인수·부하 검증은 별도입니다. 자동 복구·롤백·사용자별 권한·프로젝트 잠금·로그 순환은 미제공이며 알림·배지·새 요청 자동 감지는 비활성화/보류 상태입니다.

## 기존 파일과 생성 도구 취급

사용자가 삭제한 `*_Beta.docx`, `*_Beta.pptx`를 복원하지 않았습니다. 필요하면 Git 이력의 해당 시점에서 별도 작업 폴더로 확인하세요. 현재 문서에서 삭제된 파일로 연결하던 링크는 제거했습니다.

[베타 내용 원본](tools/beta_content.py), [베타 생성 도구](tools/build_beta_documents.py), [운영본 생성 도구](tools/build_release_documents.py), [운영본 검증 도구](tools/verify_release_documents.py), [당시 생성 기록](release-manifest.json)은 **당시 자료를 위한 도구·기록**입니다. 최신 화면 계약을 자동 반영하는 도구가 아닙니다. 운영본 생성·검증 도구는 삭제된 베타 입력을 전제로 하므로 현재 저장소에서 그대로 실행하는 절차를 안내하지 않습니다.

Office에서 직접 수정한 내용을 자동 생성 원본이 모두 포함한다고 가정하지 마세요. 재생성이 필요하면 별도 폴더에서 필요한 입력과 기준을 먼저 준비하고 결과를 비교·병합합니다. 기존 생성기는 이전 베타본을 덮어쓸 수 있고, 운영본 생성기의 해시 보호도 수동 수정 내용의 자동 병합을 뜻하지 않습니다.

현재 안내를 고칠 때는 도움말·관련 README·CURRENT_BEHAVIOR·체크리스트를 함께 확인합니다. 정책·계약·버튼·파일 경로가 바뀌면 기준 커밋과 검증 범위도 기록하고, API Key·암호·실환경 로그는 자료에 넣지 않습니다.
