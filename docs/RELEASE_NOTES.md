## 2026-10-23 베타 문서 이후 반영

- **실제 요청 검증**: 사용자·보안 그룹·요청 폴더·현재 ACL 또는 생성 준비 상태를 `/validate`로 읽기 전용 확인합니다. 화면 로그는 항목별 결과, 파일은 상세 JSON을 기록합니다. `All`은 별도 검증에서 제외합니다. 기존 `/preview`는 실행 계획 계산용으로 남습니다.
- **목록 조작**: 양쪽 목록 우클릭 행/선택 행/전체 삭제, 권한 BUS 행 읽기 전용과 수동·직접 Excel 입력 편집, 점선 포커스 숨김을 반영합니다.
- **신규 프로젝트**: BUS 원본·서버 기술 상세와 8단계 진행, 긴 오류 스크롤·원문 복사, BUS 완료 재확인을 제공합니다. 최신 서버의 실제 성공·대상 일치가 확인된 경우에만 완료합니다.
- **진행 표시**: 각 요청 시작 시 처리 행 자동 선택, 양쪽 탭 회전 표시, 서버 조회 응답별 단계 전환, 새 작업마다 경과 시간 초기화·완료 시 정지.
- **공통 화면**: 선택 건수·목록 높이·하단 간격 통일, 도움말 명칭, 누락값 `-`, 설정 메뉴 정렬과 공통 상세 열 토글. 신규 탭 생성·재조회 후에도 상세 열 설정을 적용합니다.
- **기존 기능 유지**: 단일 상세 로그 파일, 실패 권한의 명시적 부분 재실행, 시작 로딩·간단 로그인과 저장 선택. 알림·배지는 주석 처리 상태이며 새 요청 자동 감지 확대는 보류입니다.

## 검증 방법과 결과

```bash
# 저장소 루트; PyQt5 및 Client 의존성이 설치된 Python 사용
QT_QPA_PLATFORM=offscreen XDG_CACHE_HOME=/tmp/fgt-cache \
  API/.venv/bin/python -m unittest discover -s Client/tests
# API 작업 폴더에서 실행
cd API
.venv/bin/python -m pytest tests -q
```

- Client: **125개 통과**, 약 11초. HTTP·BUS 테스트 대역을 사용합니다.
- API: **76개 통과·5개 건너뜀**, 약 2초. 선택 시험은 `FGT_TEST_POWERSHELL` 인터프리터 설정이 필요합니다. 이 시험도 스텁 cmdlet 기반이며 실제 AD·SMB 변경을 대신하지 않습니다.
- API 시험에서 보이는 기존 경고 3개는 Starlette TestClient의 `httpx` 사용과 HTTP 422 상수 이름의 폐기 예정 경고입니다.
- 문서: Word 3개·PPT 2개를 LibreOffice로 PDF 변환하고 페이지·슬라이드 배치를 검토했습니다. ZIP/XML·링크·생성 덮어쓰기 방지와 기존 베타본 보존도 확인합니다.
- 실제 Windows·Chrome·BUS·AD·SMB, 실제 업무 인수·성능·부하 검증은 이번 문서 작업에서 수행하지 않았습니다.

## 범위 밖·미제공 사항

서비스 재시작 뒤 진행 Job 자동 재개, 내구성 큐·외부 Worker, 자동 AD/ACL 롤백, 사용자별 인증·권한, 프로젝트 단위 잠금, 자동 로그 순환·보관은 후속 개선 과제입니다. 문서의 개발 완료 표기는 이런 항목의 완료나 오픈 승인까지 의미하지 않습니다.

## 문서 보존과 수정

사용자가 수정한 기존 `*_Beta.docx`, `*_Beta.pptx`, `beta-assets/`, 베타 내용·생성 도구는 보존합니다. 최신 운영본은 기존 편집본을 입력으로 복사해 수정·보강했습니다. 생성 도구는 기존 파일을 기본적으로 덮어쓰지 않으며 해시가 달라진 운영본은 `--refresh`로도 덮어쓰지 않습니다. [문서 수정 원칙](README.md#운영-문서-수정생성)을 따릅니다.
